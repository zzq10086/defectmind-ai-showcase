可测的性能增益。

研究重点“龟裂”的 AP50-95 上，D 组为 0.1022，与 B 组 0.1027 基本持平，并低于 C 组 0.1096。扩散增强没有超过程序化增强。

准确表述：龟裂 AP50-95 上，D − B = −0.0005，D − C = −0.0074；在单 seed、无显著性检验条件下，只能视为方向性结果，不能宣称扩散增强有效。

LIMITS

必须说清楚的边界

  1. 单 seed、无重复训练没有多 seed 与显著性检验，结论只具方向性。
  2. 20% 子集为单类纯净样本A 组包含混标样本，A 与 B/C/D 不是严格同分布比较。
  3. C / D 增强强度不等价D 为“少而深”的局部压暗，C 为“多而浅”的均匀压暗。
  4. A 组沿用第一阶段 v1 结果v2 已删除 2 行重复标签，差异低于评估噪声。
